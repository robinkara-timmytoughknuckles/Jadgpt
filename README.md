# Jadgpt
3 saker som fungerar bra

1. Boten fungerade stabilt.

2. Koden har enkel och tydlig struktur, om jag märker ett problem så är det enkelt att hitta det och ändra.

3. "import random" gör boten mer levande. När den har random svar så ser det mer levande ut.

3 saker som inte fungerar

1. Det fanns inte så mycket som fungerade dåligt men efter ett litet tag så lyckades jag hitta något. 
==================================================
Welcome to JadGPT! Type 'exit' to quit.
==================================================

You: hi
JadGPT: What's up? How are you?

You: im good what about you
JadGPT: That's great to hear
Istället för att berätta att den mår bra som den ska göra eftersom “what about you” är ett nyckelord så säger den “Thats great to hear” och anledningen till det är för att “good” är också ett nyckelord och eftersom den sitter förre “what about you” så väljer AI:n att svara på “good” istället.

2. Det finns för lite itense så konversationer dör enkelt

3. Ingen hantering av stavfel
Om användaren skriver “helo” istället för “hello”.  Då missar boten det helt.

Fungerar chatboten bättre nu?
Ja, chatboten fungerar bättre än tidigare. Den ger mer relevanta svar och hanterar användarens input på ett mer stabilt sätt.

Förstår den fler frågor?
Ja, chatboten kan nu hantera fler typer av frågor och variationer. Den känner igen fler ord och uttryck, vilket gör att den kan svara på ett bredare sätt av input jämfört med tidigare version.

Finns det fortfarande problem?

Ja, det finns fortfarande vissa problem kvar. Chatboten är fortfarande regelbaserad och har ingen riktig förståelse för kontext eller meningar, vilket gör att den ibland kan misstolka vad användaren menar
